# Changelog

All notable changes to this package will be documented here.

## [0.1.0] - 2026-10-12

### Added

- Initial public release of the native PHP adapter implementing `wilycode/session`.
- Namespace-scoped access to native `$_SESSION` and lazy session initialization.
- Native session lifecycle operations: `start()`, `save()`, `regenerate()`, `destroy()`.
- Expanded PHPUnit coverage with isolated temporary PHP session storage.
- GitHub Actions PHP 8.4 test workflow and developer documentation.
